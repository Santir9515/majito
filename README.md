# Majito

Sistema interno de gestión de pedidos por tickets para **Cerámica Maja SRL**, desarrollado como Trabajo Final Integrador de la Tecnicatura Universitaria en Programación.

## Problema

El proceso de pedidos (vendedor → administración → depósito → facturación) se gestiona hoy de forma manual, por papel, WhatsApp y comunicación oral, generando pérdida de información y falta de trazabilidad.

## Objetivo

Digitalizar el circuito de pedidos mediante un sistema de tickets con estados, trazabilidad y control de stock centralizado.

## Integrantes

- Santiago Rodriguez — Backend, modelado de datos, lógica de negocio
- Maximiliano Yamil Rojas — Frontend, relevamiento funcional con la empresa

## Stack tecnológico

- **Frontend:** React + TypeScript
- **Backend:** Node.js + NestJS
- **Base de datos:** MongoDB (MongoDB Atlas)
- **Despliegue:** Vercel (frontend) · Render (backend) · MongoDB Atlas (DB)

## Estructura del repositorio
